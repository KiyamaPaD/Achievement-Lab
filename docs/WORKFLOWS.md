# 🧪 Workflows — exerciții în Achievement Lab

Acest laborator folosește modificări reale de fișiere pentru a învăța GitHub. Nu este necesar să scriem zeci de commit-uri inutile.

## 01. Primul PR personal

**Scop:** să exersezi un pull request de la început până la sfârșit și să faci o îmbunătățire vizibilă.

1. Deschide `docs/ROADMAP.md` pe GitHub și alege o formulare care poate fi clarificată sau o informație care trebuie actualizată.
2. Apasă **Edit this file** (creionul).
3. Modifică efectiv textul; la commit alege **Create a new branch for this commit and start a pull request**.
4. Scrie un titlu care explică schimbarea, apoi creează PR-ul sub contul **KiyamaPaD**.
5. Verifică tab-ul **Files changed**, apoi fă merge dacă modificarea este corectă.
6. Repetă pe altă problemă reală pentru a exersa încă un ciclu de dezvoltare.

**Pull Shark** are ca țintă de bază 2 PR-uri acceptate, dar badge-ul nu este garantat până nu apare oficial pe profil.

## 02. Un issue rezolvat rapid

**Scop:** să exersezi trierea și închiderea unui issue mic.

Identifică înainte o problemă clară, care poate fi rezolvată imediat. Creează issue-ul, efectuează corectura și închide-l în cel mult 5 minute, dacă este într-adevăr rezolvat. Criteriul comunitar pentru **Quickdraw** este închiderea unui issue sau PR în acest interval.

Nu crea și închide issue-uri goale doar pentru un badge.

## 03. Merge fără review — într-un repo de laborator

Într-un proiect personal unde nu există regulă care să impună review, un PR creat de tine și acceptat fără review poate îndeplini condiția pentru **YOLO**. Folosește un PR cu o modificare bună, pe care ai verificat-o înainte de merge.

## 04. Colaborare autentică

Lucrează efectiv cu un coleg la un fișier sau la un proiect. Pentru un commit făcut împreună, GitHub acceptă trailerul de commit:

```text
Co-authored-by: Prenume Nume <email-asociat-contului-GitHub>
```

Folosește numai numele și emailul oferite/acceptate de coleg. Include commit-ul într-un PR și fă merge. Badge-ul **Pair Extraordinaire** depinde de atribuirea corectă a coautorului.

## 05. Achievements care cer alt context

- **Galaxy Brain:** ajută alți utilizatori cu răspunsuri acceptate în GitHub Discussions unde această funcție este disponibilă.
- **Starstruck:** îmbunătățește un proiect **public** care poate primi stele reale. Un repo privat nu este potrivit.
- **Public Sponsor:** opțional, implică o plată. Nu este necesar pentru acest laborator.
