# 🏆 GitHub Achievements — ghidul laboratorului

> **Important:** acestea sunt achievement-uri acordate automat de GitHub, nu stickere pe care le punem noi în README. Condițiile detaliate provin dintr-un catalog comunitar; mecanismul GitHub poate fi actualizat.

## Achievement-uri disponibile

| Achievement | Condiție de bază | Niveluri suplimentare | În repo privat? |
|---|---|---|---|
| ⚡ Quickdraw | Închide un issue sau un PR în cel mult 5 minute de la creare | Nu | Da, cu acțiune autentică |
| 🚀 YOLO | Fă merge la propriul PR fără review | Nu | Da, dacă repo-ul permite |
| 🦈 Pull Shark | 2 PR-uri ale tale acceptate prin merge | 16 / 128 / 1024 | Da |
| 🤝 Pair Extraordinaire | Commit cu coautor real, inclus într-un PR acceptat | 10 / 24 / 48 | Da |
| 🧠 Galaxy Brain | 2 răspunsuri marcate ca acceptate în Discussions | 8 / 16 / 32 | În Discussions unde funcția este activă |
| ⭐ Starstruck | Repository creat de tine care atinge 16 stele | 128 / 512 / 4096 | **Nu, pentru că repository-urile private nu pot fi steluțate public** |
| 💜 Public Sponsor | Sponsorizezi prin GitHub Sponsors | Nu | Nu ține de acest repo; implică plată |

Nivelurile suplimentare sunt praguri comunitar documentate, nu progres oficial afișat aici.

### Nu le urmărim artificial

- **Quickdraw:** gestionează o problemă mică, reală, care chiar se rezolvă rapid. Nu crea issue-uri doar ca să le închizi.
- **YOLO:** e un experiment de lucru pe un repo personal. Pe proiectele de echipă review-ul rămâne o practică bună.
- **Pull Shark:** deschide două PR-uri cu schimbări utile — documentație, teste, corecturi reale.
- **Pair Extraordinaire:** un coautor trebuie să fi contribuit efectiv. Mențiunea `Co-authored-by:` nu e o invitație să atribui munca fictiv.
- **Galaxy Brain:** răspunde util la întrebări reale. Nu încerca să generezi discuții artificiale. Răspunsurile din comunitatea centrală GitHub nu mai contează din februarie 2024, conform catalogului comunitar.
- **Starstruck:** lucrează la un proiect public de care oamenii chiar au nevoie. Nu schimba acest repo în public doar pentru stele.

## Ce nu mai poate fi obținut în mod obișnuit

**Arctic Code Vault Contributor** și **Mars 2020 Contributor** țin de evenimente istorice. Unele badge-uri experimentale, precum **Open Sourcerer** și **Heart On Your Sleeve**, sunt marcate dezactivate de catalogul comunitar. Nu le punem ca obiective active.

## 🛡️ Confidențialitate și afișare

GitHub poate include contribuțiile private la Achievements, dar trebuie să alegi să le afișezi:

1. Accesează profilul → **Contribution settings** → activează **Private contributions**.
2. Accesează **Settings** → setările profilului → activează **Show Achievements on my profile**.
3. Păstrează repository-ul **Private**. Publicul nu vede codul și detaliile private ale evenimentelor.
4. **Dacă profilul în întregime este privat**, Achievements nu sunt afișate public.

Acțiunile realizate de un bot, automatizare sau o integrare pot fi atribuite acelui cont, nu neapărat proprietarului. Pentru un achievement personal, folosește propriul cont GitHub.
