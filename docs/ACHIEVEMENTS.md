# 🏆 GitHub Achievements — catalog complet

> Ultima verificare: **16 noiembrie 2026**. GitHub spune că Achievements sunt încă în **public preview**, iar criteriile exacte și pragurile nu sunt toate documentate oficial. Tabelul folosește informații publicate de GitHub și praguri confirmate de comunitate. Nu confunda badge-urile decorative din README cu achievement-urile reale.

## 1. Cele 7 achievement-uri care se pot obține în prezent

| Achievement | Cum se deblochează | Default → Bronze → Silver → Gold | Situație |
| :--- | :--- | :--- | :--- |
| 🦈 **Pull Shark** | PR-uri ale tale acceptate prin merge | **2 → 16 → 128 → 1.024** merged PRs | ✅ Deblocat (confirmat de proprietar) |
| ⚡ **Quickdraw** | Închizi un issue sau PR în maximum 5 minute de la creare | **1**, fără niveluri | ✅ Deblocat (confirmat de proprietar) |
| 🚀 **YOLO** | Faci merge la un PR fără review | **1**, fără niveluri | ✅ Deblocat — confirmat de proprietar pe **19.11.2026**, după [PR #3](https://github.com/KiyamaPaD/Achievement-Lab/pull/3) și [PR #7](https://github.com/KiyamaPaD/Achievement-Lab/pull/7) |
| 🤝 **Pair Extraordinaire** | Ai un commit *co-authored* în PR acceptat | **1 → 10 → 24 → 48** | ⬜ De obținut |
| 🧠 **Galaxy Brain** | Un răspuns al tău este acceptat într-un GitHub Discussion de tip Q&A | **2 → 8 → 16 → 32** răspunsuri | ⬜ De obținut |
| ⭐ **Starstruck** | Un repository creat de tine atinge pragul de stele | **16 → 128 → 512 → 4.096** stele | ⬜ De obținut |
| 💜 **Public Sponsor** | Susții public un proiect/dezvoltator prin GitHub Sponsors | **1**, fără niveluri | ⬜ Opțional; implică bani |

Nivelurile suplimentare sunt **praguri comunitar documentate**, nu date citite în timp real din cont.

### 🔒 Ce se poate obține dintr-un repo privat?

- **YOLO, Pull Shark și Quickdraw:** se pot obține din activități eligibile în repo-uri private.
- **Pair Extraordinaire:** da, cu un colaborator real și un co-authored commit atribuit corect.
- **Galaxy Brain:** presupune Q&A în GitHub Discussions și acceptarea unui răspuns; *nu* poate fi obținut doar prin modificarea README-ului din acest lab.
- **Starstruck:** are nevoie de un **repository public**, deoarece repo-urile private nu primesc stele publice.
- **Public Sponsor:** ține de GitHub Sponsors, nu de activitatea în repository; este **opțional și plătit**.

**Nu este posibil să obții toate cele șapte doar prin editarea unui singur repository privat.**

## 2. Pași concreți pentru cele patru rămase

### 🚀 YOLO

1. Intră din propriul cont GitHub într-un repo personal unde ai permisiuni de merge.
2. Creează o ramură și modifică *ceva real*: o instrucțiune incompletă, un link stricat ori o corectură necesară.
3. Deschide un pull request și examinează singur diferențele.
4. Fă merge fără review *doar dacă regulile repo-ului permit*. Nu dezactiva protecțiile de pe repository-urile serioase de echipă pentru a obține badge-ul.
5. Verifică badge-ul pe profil — atribuirea este făcută de GitHub, nu de acest fișier.

### 🤝 Pair Extraordinaire

1. Lucrează efectiv cu o altă persoană la o schimbare.
2. Fă un commit care reflectă contribuția ambilor autori, cu trailerul:
   
   ```text
   Co-authored-by: Nume Colaborator <email-asociat-contului-GitHub>
   ```

3. Include commit-ul într-un PR și fă merge. Asigură-te că numele/emailul coautorului sunt reale și aprobate de acesta.
4. Verifică dacă GitHub atribuie corect commit-ul și badge-ul.

### 🧠 Galaxy Brain

1. Identifică întrebări reale în **GitHub Discussions**, la repo-uri sau comunități cu categoria **Q&A**.
2. Răspunde clar, cu explicații și, dacă e cazul, cod și surse.
3. Proprietarul întrebării sau maintainerul marchează răspunsul drept **accepted**. Nu poți controla această decizie.
4. Ținta inițială este **2 răspunsuri acceptate**. Nu crea întrebări fictive și nu cere acceptări artificiale.

### ⭐ Starstruck

1. Alege un proiect **public** creat de tine: [Mars Atlas](https://github.com/KiyamaPaD/InfotronX-Horizon), [MathHard](https://github.com/KiyamaPaD/MathHard) sau [FTC Programming Atlas](https://github.com/KiyamaPaD/FTC-Programming-Atlas).
2. Îmbunătățește documentația, calitatea proiectului și exemplele de utilizare.
3. Fă-l util comunității. **16 stele reale** reprezintă primul prag.
4. Nu cumpăra stele și nu organiza schimburi de stele.

### 💜 Public Sponsor

Susținerea unui maintainer prin **GitHub Sponsors** poate debloca badge-ul dacă sponsorizarea este publică. **Nu recomand cheltuiala doar pentru achievement**; nu este o cerință pentru a lucra la proiectul nostru.

## 4. Profile Highlights — altă categorie

Acestea sunt **badge-uri de program/status**, diferite de GitHub Achievements:

- **PRO** — abonament sau statut GitHub Pro.
- **Developer Program Member** — membru al programului GitHub Developer.
- **GitHub Campus Expert** — participare la programul de campus.
- **Security Advisory Credit** — credit recunoscut pentru o vulnerabilitate acceptată.
- **Security Bug Bounty Hunter** — participare recunoscută la programul de bug bounty GitHub.

Nu sunt incluse în cele șapte Achievements urmărite aici. Badge-urile de personal GitHub intern, dacă există, nu sunt obiective pentru conturile obișnuite.

## 5. Afișare și confidențialitate

- În [Contribution settings](https://github.com/settings/profile) poți permite includerea contribuțiilor private și afișarea Achievements.
- Detaliile evenimentelor din repository-uri private rămân ascunse vizitatorilor fără acces.
- Dacă faci modificări prin integrare/bot, este posibil ca GitHub să crediteze contul integrării. Pentru un achievement personal, efectuează acțiunile eligibile în contul propriu.
- Din septembrie 2026, GitHub afișează pe profil nivelul cel mai mare al unui achievement cu tier-uri.
